# 石油勘探开发的智能化可能性地图 · 案例集

按石油作业链条逐环节展示可被深度学习改造的候选场景，标注 AI 介入点、数据条件与难度等级，并附带可运行的案例示范。

站点是**纯前端、零依赖**的：双击根目录的 `index.html` 即可打开（建议 Chrome / Edge），无需安装、无需服务器、无需联网。

## 内容规模

- 13 个作业环节、61 个场景、61 个案例，全部接入
- 每个案例含：四段专业背景、数据清单、五步流程、可运行示范入口
- 一套「地质剖面」可视化语言，在首页 / 作业链页 / 环节页 / 场景页 / 方法页五处复用

## 目录结构

```
index.html                 站点入口
assets/
  data.js                  13 个环节、61 个场景的元数据
  core/                    外壳、组件、剖面可视化、案例宿主、上传与打包加载
  cases/                   插件形式的案例
  packs/_all.pack.js       60 个内置案例包的汇总产物（站点直接加载）
```

## 使用

直接打开 `index.html`：

- **首页**：按环节浏览，或按 AI 方法反查
- **案例库**：61 个案例的接入状态
- **场景页**：01 专业背景 / 02 案例流程 / 03 可运行示范 三个 tab
- **首页 00 剖面**：可交互的储层剖面，悬停色块 / 井 / 断层可看深度与工程含义
- **右上角「＋ 添加案例」**：把案例文件夹拖进去即可导入

## 说明

案例中的示范数据均为教学用的合成 / 简化数据，不对应真实油田资料。每个案例里都写了真实落地所需的数据条件与失败模式。个别浏览器对本地 `iframe srcdoc` 有限制，若示范页空白，请用 Edge / Chrome 打开。
